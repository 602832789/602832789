## 🌾 精选项目

<div align="center">

| &nbsp; | 项目 | 简介 | 技术栈 |
|:---:|:---|:---|:---:|
| <img src="https://raw.githubusercontent.com/602832789/602832789/main/assets/qq-farm-bot.svg" width="32" height="32" alt="qq-farm-bot"> | [**qq-farm-bot**](https://github.com/602832789/qq-farm-bot) | QQ 农场 · 牧场自动化控制台：TypeScript 后端直连游戏 WebSocket 与 Protobuf 协议，多账号统一调度种植、养殖、好友互动与活动任务 | `TypeScript` `Vue 3` |

</div>

<br/>

**核心能力**

- **协议直连** —— 不依赖浏览器，也不靠模拟点击；后端直接维持 WebSocket + Protobuf 会话，业务逻辑全跑在 Node.js 里
- **多账号调度** —— 每账号一个独立宿主进程，连接与心跳托管在宿主侧，worker 热重启不掉线
- **可视控制台** —— Vue 3 + Vite + Tailwind 面板，策略配置、作物图鉴、今日统计、实时日志一屏看完
- **数据自持** —— 账号与运行数据全部落在本地 `core/data`，不上传第三方
- **工程化交付** —— 1000+ 后端测试、300+ 前端测试，Docker 一键部署
